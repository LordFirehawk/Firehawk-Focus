### Fitness snacking during breaks

Let people optionally use a focus break for a short fitness session. Keep the session library open so exercises and routines can be added or changed over time.

- [ ] Offer optional fitness sessions during breaks without making them interrupt the regular break flow.
- [ ] Create a **5-minute mini-session** option for quick movement, including explosive movements and other short activities.
- [ ] Create a **15-minute focused-session** option for a more deliberate workout.
- [ ] Make sessions editable: give each activity a name, a short explanation, and a duration or target (such as reps or sets).
- [ ] Allow an optional picture or illustration for each activity.
- [ ] Show checkboxes or set counters beside activities so it is easy to mark what was completed and see progress through a session.
- [ ] Track completed fitness time for the day and show the total in minutes or hours.
- [ ] Decide whether daily totals should count elapsed session time, completed activity time, or both.
